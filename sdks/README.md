# HolidayOps SDKs

Clients for the public API (countries, holidays, business days), generated from the public part
of `backend/schema.yml`. Organization management stays in the web app and isn't in the SDKs.

| Language | Folder | Generated by |
|---|---|---|
| Python 3.10+ | `python/` (package `holidayops`) | openapi-python-client 0.27.1 |
| TypeScript | `typescript/` (package `@holidayops/sdk`) | openapi-typescript 7.13.0 + openapi-fetch |

## Python

```python
import datetime
from holidayops import AuthenticatedClient
from holidayops.api.business_days import business_days_check_retrieve

client = AuthenticatedClient(base_url="https://holidayops.ahmershah.dev", token="hops_...")
day = business_days_check_retrieve.sync(client=client, country="SA", date=datetime.date(2027, 4, 2))
print(day.is_business_day, day.reason)  # False weekend
```

## TypeScript

```ts
import { holidayops } from "@holidayops/sdk";

const api = holidayops({ apiKey: "hops_..." });
const { data } = await api.check({ country: "PK", date: "2027-03-23" });
console.log(data?.is_business_day, data?.holidays); // false ["Pakistan Day"]
```

## Regenerate after an API change

From the repository root: `npm run sdks`. It rewrites `public-schema.yml`, the Python package and
`typescript/src/schema.d.ts`; commit the result with the API change.
